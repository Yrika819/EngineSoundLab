# EngineSoundLab — P1 sound-engine upgrade

From the repository root:

```sh
npm install
npm run dev
npm run check
```

The first Web prototype is a **generic inline-4 gasoline engine**. It is not a validated Prius or Aura calibration. It uses only original procedurally synthesized audio generated by the Web Audio API; no recorded sound assets are needed. The P1 engine uses four-cylinder firing events in a 720-degree cycle, paired pulse envelopes, fixed exhaust resonators, intake turbulence, and load-dependent timbre. Deterministic offline wave tests cover signal bounds, engine order and transitions.

- Start engine with a click/tap (browser autoplay policy).
- Hold accelerator to accelerate; move finger down to reduce throttle.
- Hold brake to decelerate; speed and RPM appear in a generic meter.
- Leaving the tab clears inputs and suspends audio. A user gesture is required to resume.
- Where AudioWorklet is unsupported, a simpler oscillator sound path is used and labeled accordingly.
- PWA/offline caching is **not implemented yet**. Approximate THS and e-POWER controllers exist, but they are **not OEM validated**.

`npm run build` outputs static files to `dist/web`, suitable for future GitHub Pages deployment.

## Analog pedal improvements

On touchscreens, the accelerator and brake now act as **position-based vertical analog pedals**. Touch a point on the pedal: the bottom is 0%, the top is 100%; dragging up or down adjusts the output in 5% steps. The live fill and percentage update together. Lifting a finger, cancellation, lost capture, tab hiding, and focus loss reset the pedal to 0%. Arrow keys / PageUp / PageDown are supported while held for keyboard accessibility. This avoids the previous instant-100%-then-drag-down behavior.

## I3 / I4 / I6 synthesized sound profiles

The UI now includes an **audio-only** selector for inline 3-, 4- and 6-cylinder four-stroke configurations. The engine firing events change from every 240° (I3) to 180° (I4) or 120° (I6) over a 720° crank cycle, with distinct pulse gain and mechanical-order coloration. The selector can be changed while playing without restarting the driving simulation. **Vehicle performance/gear ratios do not change yet**, so this is a sound-engine study and not a full I3/I6 vehicle simulation. No recorded samples or factory-calibrated engine profiles are included.

## P2 estimated hybrid topologies

The page can select a generic gasoline drivetrain, a conceptual Toyota Prius 60-series power-split HEV, or a conceptual Nissan Aura FE13 series HEV. Displayed hybrid data includes SOC, engine phase, drive motor and generator power; motor whine is synthesized separately from combustion. Manufacturer ECU thresholds, motor/battery ratings and power-split tooth counts are **not calibrated**, and numeric values are placeholders. Prius sounds default to I4 and Aura to I3; the user can override sound cylinder count independently of the simulated drivetrain.

Tests cover e-POWER engine/wheel disconnection, Prius planetary kinematics, energy accounting, start/stop state, regeneration and EV-only acoustic output.

## P3 manufacturer-inspired original gauge skins

Choose the meter style without changing the driving or audio simulation:

- AUTO: Prius horizontal speed/CHARGE-ECO-POWER, Aura Classic twin power/speed dials, generic SPORT.
- SPORT: original RPM/speed dial.
- ENGINEERING: shared physical/electric telemetry from DriveState, including SOC, motor/generator/battery power.
- AURA ENHANCED: Aura-only central energy flow with compact power and speed rings.

The illustrations and normalized gauge scales are **original approximations**; no OEM images or proprietary UI assets are copied. Read [Gauge details](../../docs/GAUGES.md).
