# EngineSoundLab — P1 sound-engine upgrade

From the repository root:

```sh
npm install
npm run dev
npm run check
```

The first Web prototype is a **generic inline-4 gasoline engine**. It is not a validated Prius or Aura calibration. It uses only original procedurally synthesized audio generated by the Web Audio API; no recorded sound assets are needed. The P1 engine uses four-cylinder firing events in a 720-degree cycle, paired pulse envelopes, fixed exhaust resonators, intake turbulence, and load-dependent timbre. Deterministic offline wave tests cover signal bounds, engine order and transitions.

- Start engine with a click/tap (browser autoplay policy).
- Hold accelerator to accelerate; move finger down to reduce throttle.
- Hold brake to decelerate; speed and RPM appear in a generic meter.
- Leaving the tab clears inputs and suspends audio. A user gesture is required to resume.
- Where AudioWorklet is unsupported, a simpler oscillator sound path is used and labeled accordingly.
- PWA/offline caching and dedicated THS/e-POWER controllers are **not implemented yet**.

`npm run build` outputs static files to `dist/web`, suitable for future GitHub Pages deployment.

## Analog pedal improvements

On touchscreens, the accelerator and brake now act as **position-based vertical analog pedals**. Touch a point on the pedal: the bottom is 0%, the top is 100%; dragging up or down adjusts the output in 5% steps. The live fill and percentage update together. Lifting a finger, cancellation, lost capture, tab hiding, and focus loss reset the pedal to 0%. Arrow keys / PageUp / PageDown are supported while held for keyboard accessibility. This avoids the previous instant-100%-then-drag-down behavior.
