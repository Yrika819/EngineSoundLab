# P5-B 車種別エンジン音響設計 — PRIUS 2.0 HEV / AURA FE13

本設計は**録音を使用しないオリジナル合成**。2026-11-04調査の[参考資料・音源の区別](P5_PRIUS_AURA_SOUND_RESEARCH.md)に従うが、音圧トレースやメーカー校正済みのECU音響マップを再現したとは主張しない。

## 専用ICE音響エンジン

新規 `apps/web/public/vehicle-combustion.js` は次の独立した成分を生成する。

1. **四行程クランク同期点火**：720°で直4は4回（180°間隔）、直3は3回（240°間隔）。定常3000rpmで理論的点火頻度は100Hz/75Hz。点火のばらつきは小さい固定係数で再現する。
2. **燃焼圧力パルス**：速い立上がり/短・中・長の指数減衰を組み合わせ、単一の正弦波だけでなく、負荷に応じて変化する排気の基本的な脈動をつくる。
3. **吸排気管の共鳴**：プリウス向け低・中域（98Hz／204Hz）、オーラ向け（83Hz／267Hz）の独立した安定二次共鳴器を使う。これらの値は**合成チューニング上の仮値**で、実車の測定ピークではない。
4. **吸気乱流**：速度・スロットル・負荷でローパス周波数と音量が変化するシード固定ノイズ。燃焼レイヤーから独立した乱流過程。
5. **クランク/バルブの次数成分**：クランク角度に位相同期した機械音を追加。汎用ピッチ発振器の上に貼り付ける方式ではなく、回転幾何に従う。
6. **燃焼しないエンジン回転**：P5-Aの `STARTING` / `SPINNING_UNFUELLED` / `STOPPING` では、機械的なクランク回転音は小音量で残し、**新しい燃焼点火イベントを完全停止**する。残った排気共鳴は自然減衰する。
7. **車室方向の周波数補正**：プリウスは365Hz近辺の中域を暫定的に約4.8dB減衰、オーラはより弱い約1.5dB減衰。**特定周波数・Q・dBは公式EQ値ではなく、聴感調整用の初期値**。

## 車両による違い

| 成分 | 60プリウス MXWH60 2.0L | オーラFE13 |
| --- | --- | --- |
| 燃焼点火 | 直列4気筒・2次の点火基本次数 | 直列3気筒・1.5次の点火基本次数 |
| エンジン役割 | 機械駆動＋発電 | 発電のみ。車輪への機械結合は存在しない |
| 車室音色の方向性 | 開発講演の「加速時の低域強調・中域抑制」を参考 | 3気筒特性を維持しつつ、バランサーと遮音の意図を考慮し粗さを誇張しない |
| 始動・停止 | 点火/排気共鳴の自然なフェード、クランクが回る音 | 同じ物理的過渡経路、発電要求で鳴る状況が異なる |
| 音の出ない状況 | EV走行時はICE点火ゼロ | 駆動モーターだけのEV、非燃焼のエンジン回転でもICE点火ゼロ |

データの正確性は `DriveState` → `toAudioTelemetry` のP5-A契約を使用し、メーター・UIから音の発生条件を推測しない。**音量/フィルターの実車比較は未実施**。車外警報音（AVAS）はこのレイヤーに含めない。

## ミキシング・可用性

- `synth-core.js` で「既存の汎用I3/I4/I6エンジン」と「車種専用ICE音」を約80msでクロスフェード。電動系 `electric-synth.js`、ロードノイズは別バス。
- Workletへ `iceVehicle`（0汎用/1プリウス/2オーラ）と `engineOperation`（停止・始動・燃焼・非燃焼回転・停止動作の整数状態）を追加。離散状態コードはAudioParamで**補間しない**（状態の中間値で誤燃焼することを防止）。
- **初期状態の燃焼デフォルトはOFF**。正確な車両テレメトリーが届くまで、エンジンを勝手に鳴らさない。
- オフライン利用時にもモジュールが必ずキャッシュされるよう、PWAのビルド時プリキャッシュリストと検証項目を更新。
- `VehicleCombustionSynth` は音響コールバックで動的配列を確保しない。連続のフィルター/EQで切替時のクリックを減少。

## 合格テスト

`tests/p5b-vehicle-combustion.test.mjs`、`tests/worklet-bridge.test.mjs`、PWAテストを継続。44.1/48/96kHzの有限性/ピーク、点火タイミング、燃焼なし始動回転、加速負荷、車種音色差、プロファイル切替、決定論的波形を検証する。

### まだ未検証なこと

- 実車録音の客観FFTまたはラウドネス比較、同じ録音位置・同じエンジン負荷でのA/B。公開動画の説明文から測定済み周波数値を推定しない。
- 実際のエンジン室/車室内の吸排気音圧伝達関数、マイク/スピーカー特性。P5-Dで別途ミキサー・マスキングを設計。
- 聴感・音質・端末負荷の実機評価。自動テストPASSは実車音の忠実度を証明しない。
