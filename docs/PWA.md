# P4 — PWA and mobile reliability

## Shipped in the branch

- Original home-screen PNG icons (180/192/512px) plus SVG, Web App Manifest, and standalone display.
- A production-only Service Worker generated by Vite. It precaches exact hashed CSS/JS bundles and all procedural synthesizer/audio-worklet files.
- The offline worker is scoped only to the EngineSoundLab GitHub Pages path. Its activation removes only prior EngineSoundLab caches, never other app data.
- A live offline readiness indicator and an update-waiting message. Closing all tabs/installed app windows lets updated workers activate safely.
- Backgrounding and back-forward-cache restore clear throttle/brake, stop the loop and suspend audio; user tap is required to resume.
- Audio generation uses local Web Audio synthesis; no recordings, logins, telemetry upload, microphone or remote services.

## Install and offline procedure

1. Visit https://yrika819.github.io/EngineSoundLab/ while online.
2. Wait for the app to show オフライン対応済み before going offline.
3. Android Chrome: use the browser Install app/Add to Home Screen menu when available.
4. iPhone Safari: Share -> Add to Home Screen -> Open as Web App (the wording varies). In-app webviews can lack these options.
5. Reopen the installed app. For offline QA, close it, turn on airplane mode, and launch again.
6. Tap the Start simulation button to enable audio. Autoplay restrictions still apply offline.

An offline cache can be cleared by the operating system/browser, and a first visit must be online. Private browsing may disable service workers.
Apple help: https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/27/ios/27

## Technical implementation

- apps/web/vite.config.ts computes a content hash and emits dist/web/sw.js after building.
- The generated worker caches its exact HTML, app bundles, icons, and engine-worklet/synth-core/electric-synth modules.
- All precache URLs resolve relative to registration.scope; it handles GET requests only within the app's path and origin.
- Navigation uses the cached matching app shell, preserving offline consistency. Non-cached requests can use the network.
- The worker does not force skipWaiting, preventing mid-drive replacement of scripts.
- User inputs and vehicle telemetry are never persisted in browser storage.

## Automated checks

Run npm run check. This performs TypeScript typecheck, all normal tests, Vite production build, then tests/pwa-build.verify.mjs.
The post-build suite checks icon PNG headers and sizes, manifest start URL/scope, all hashed assets, worker cache scopes, offline navigation and unrelated cache preservation with a simulated worker environment.
