# P5 事前調査：プリウス60系 2.0 HEV／オーラFE13の音響特性

調査日: 2026-11-04。**研究・音響設計のみ**。P5のDSPや車両制御コードはこのドキュメントでは変更しない。

## 対象と混同禁止
- Toyota Prius 60系 **MXWH60 2WD 2.0L HEV**、M20A-FXS、直列4気筒、第5世代ハイブリッド。PHEV（MXWH61）、1.8L（ZVW60）、4WDの後輪モーターを混ぜない。
- Nissan Aura **FE13 2WD 第2世代e-POWER**、HR12DE、直列3気筒、EM47駆動モーター。NISMOやFSNE13の後輪MM48、別車種の第3世代e-POWERエンジンとは混ぜない。

## 重要な結論：実際の「聞こえ方」は音源・制御・車室の組合せ
1. Prius（動力分割式）：走行要求によってエンジン機械出力とモーター駆動が協調。EV低速時はエンジンを停止でき、加速すると4気筒燃焼音が加わる。エンジンRPMを車速の固定倍数や有段AT変速音として扱わない。[T1][T2]
2. Aura（シリーズ式）：車輪を駆動するのはモーターのみ。発電用エンジンは車輪に機械的につながらない。エンジン回転はSOC、発電要求、暖機、空調、走行音マスキングなどに影響される。完全にアクセル無関係なのではなく、e-POWER一般技術には加速要求とエンジン音の印象を調整する考え方もある。ただし別エンジンのX-Trail向け制御値をFE13へ移植しない。[N1][N2][N3][N4]
3. オーラの「ヒューン」は**車両接近通報音**、「キーン」は**駆動モーターまたは発電機**の音として、日産のオーラ向け「簡単早わかりガイド」で明確に区別される。回生音、冷却ファン音も別成分。[N5]
4. プリウスの車両接近通報は、燃焼エンジン停止中、車速連動で鳴り約25km/h超で消音。オーラはエンジン停止中、加速時おおむね30km/h以下・減速時おおむね25km/h以下・後退時。**車内の駆動モーター音と対外向け警告音を合成音レイヤーで混ぜない。**[T1][N6]
5. プリウス開発責任者の2023年技術講演の取材報告によると、加速時のエンジン音では3000〜6000rpmに関して200〜600Hz帯の音圧を抑え、低音側を印象的にしたと説明。車内で聞こえる音の音色設計の方向性として重要。ただし特定2.0L MXWH60専用の数値EQカーブは未公開。[T3]
6. HR12DEはバランサーなどで3気筒特有の騒音・振動を抑える設計。単純に1.5次成分を過大強調した「粗い3気筒音」は実車の狙いから外れる可能性がある。[N7]
7. Nissan Technical Reviewの過去のe-POWER NVH解析では発電時のエンジン騒音、発電機の音、駆動モーター、インバーター高周波、ギア噛み合い、冷却ファン、モータートルクリップルを別々の現象に分類している。車種固有の極対数やPWM周波数を示す根拠ではない。[N8]
8. オーラのブレーキや長い下り坂ではエンジンが回っても**燃料を燃焼しない**音があり得ると公式ガイドで説明。エンジンRPM>0だから燃焼音を必ず発生させる実装は不正確。[N5]

## モデル別の音源設計（研究に基づく提案、実測値ではない）

| チャンネル | Prius 2.0 HEV | Aura FE13 |
| --- | --- | --- |
| ICE燃焼 | 直4・四行程で2.0次の点火励振、負荷で音色変化。低域主体の車室EQ方向 | 直3・四行程で1.5次の点火励振。バランサー/車室の減衰を考慮。発電中の回転パターン |
| ICE非燃焼回転 | 始動・停止の遷移は燃焼レイヤーと区別 | 下り坂/ブレーキ時の非燃焼回転を別状態として明示 |
| 駆動モーター | MG2と推定される軸回転の電磁音・ギア音 | EM47駆動モーターの電磁音・ギア音、トルク/回生で色変化 |
| 発電機 | MG1を個別音声源に（音量は実測が必要） | 発電中にエンジンと発電機を独立して鳴らす |
| インバーター/共鳴 | EV/回生時、負荷に応じた控えめな高調波 | 同上、別の推定スペクトル |
| AVAS/車両接近通報 | 独立した屋外向け音。実車警報音のコピーは不可 | 低速の「ヒューン」は音源をモーター音と区別 |
| ファン/ロード/風 | 車室音を支配する場合あり。速度依存のマスキング | 発電エンジンをロードノイズに隠す制御の影響を重視 |

**点火周期の物理的な初期値（特定車の実測スペクトルではない）**：
四行程の点火繰り返し基礎周波数は `f_firing = (RPM/60) × (cylinders/2)`。
例として3000rpmなら直4は100Hz、直3は75Hz。最終的に車室へ到達する主ピークの周波数・振幅をこの一式だけで決められるわけではない。

## 条件別に実装で比較すべき場面

| 走行条件 | Prius | Aura |
| --- | --- | --- |
| 停止→緩やかな発進 | ICE停止、MG2/路面/車両接近通報の可能性 | ICE停止、EM47/路面/車両接近通報の可能性 |
| 一定速・低負荷 | EVまたはICE協調で大きく変化 | 電動走行音中心、SOC等で発電始動もあり得る |
| アクセル要求増 | 4気筒ICEが加わる、変速ショックを模した有段AT音は不可 | EM47が即応。必要なら発電用直3ICE/発電機音が追加 |
| 燃焼エンジン始動 | 滑らかな始動遷移・トランスアクスル音 | 発電開始と発電機音、車室の暗騒音とのマスキング |
| 減速・回生 | 回生モーター音。燃焼はOFFの場合あり | 回生音と特有の高周波音。条件によって非燃焼エンジン回転 |
| 暖房・電池残量低下 | ICE始動可能、発電/暖機要求 | ICE始動可能。駆動音とエンジン発電音は独立 |

## 次の音響実装前に残る不確実性
- **動画音声の直接聴取・FFT/スペクトログラム解析は未実施**。検索で確認したのは動画の車種・録音位置・説明文。収録音声を未確認なのに「この周波数のピークが存在」とは主張しない。
- MG1/MG2、EM47、発電機の**実極対数、ギア噛み合い歯数、インバーターPWMの周波数マップ、車室内伝達関数**は未検証。P3+の数値はOEM校正ではなく合成用の仮値。
- 日産の別車種向けVCターボe-POWER技報にある「定点発電2000rpm」「2350rpm」等の値を**Aura FE13 HR12DEの定点値としては採用しない**。
- 車内視点を主音声、エンジンルーム視点を調査用に分離するのが妥当。前者では遮音・ロードノイズ・風切り音のマスキングが大きく効く。
- 公開動画の録音素材は**試聴・音響評価の参照**に限定。ライセンスのない音声抽出・再配布・サンプル取り込みは禁止。合成処理は引き続き録音不要。

### 開発順序の推奨
1. まず**音源の実在条件**（ICE燃焼/非燃焼、電動駆動、発電、回生、AVAS）を車種別状態から確定。
2. 次にエンジン4気筒と3気筒の基礎音色、MG1/MG2とEM47/発電機の独立レイヤー、車室内EQ/マスキングを調整。
3. 最後に同じ録音環境の合法に視聴できる実車参照を用いてA/B聴感と音響測定を実施し、推定値の限界を明示する。
