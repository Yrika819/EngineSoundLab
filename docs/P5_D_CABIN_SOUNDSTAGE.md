# P5-D：車室内サウンドステージ・ロードノイズ・風切り音

作成日：2026-11-04。**全音声はオリジナルのリアルタイム合成。実車録音の取り込みはありません。**

## 狙い

P5-A/B/Cでは燃焼、非燃焼クランク回転、駆動モーター、発電機の各音源を独立させた。P5-Dでは、それらが**車室内に届くときの音色と相対音量**、タイヤ/路面の走行音、空気流による風切り音を統合する。

日産は第2世代e-POWERについて、ロードノイズがエンジン音をマスクする状況で発電エンジンを作動させると説明している。これは音響設計の「速度と路面に応じて背景音が変わる」という定性的根拠である。ただしFE13固有の室内伝達関数、音量、スイッチング条件、車体共鳴の実測値ではない。

## 実装構成

追加：`apps/web/public/cabin-soundstage.js` の `CabinSoundstage`。

AudioWorkletの既存`EngineSynthCore`は以下の6バスを作り、同じ時刻の状態からミキサーに渡す。

| バス | 発音条件・入力 | 車内ミキシング |
| --- | --- | --- |
| 燃焼エンジン | 燃焼ゲートに従うP5-B燃焼音 | 推定ローパス・車種別ゲイン |
| 非燃焼クランク | STARTING/STOPPING/SPINNING_UNFUELLED | 燃焼とは独立した機械音の遮音 |
| 駆動モーター | MG2/EM47電磁音＋ギア＋インバーター＋回生 | 推定ローパス・異なる車種別ゲイン |
| 発電機 | MG1/発電機発電・スタータ | 駆動モーターより低い車内ゲイン |
| タイヤ／路面 | 車速・設定路面の粗さ・シード固定の乱流音 | 低域転動＋中域テクスチャ |
| 風切り | 車速の上昇に伴い増える広帯域ノイズ | 中高域の変動成分 |

**停車時は、路面音と風音はゼロ。** EV走行中も路面・風音は発生し、燃焼音を必要としない。音が大きな背景に埋もれて聞こえにくくなる知覚上のマスキングを主とし、追加で最大12%に限定した滑らかなパワートレインの減衰を適用。急激な音量圧縮や「ポンピング」は避ける。

### 音響視点と路面選択

Web UIから次の項目を変更できる。**車両の燃焼・トルク・SOC・速度の計算値は変更しない。**

- `CABIN`（初期状態）：車内を模した減衰、風・路面音を混ぜる。
- `ENGINE_BAY`：車外のエンジンルームで聴取する**比較用の架空視点**。音源を前面に出し、風/タイヤの混合量を下げる。実車のエンジンルーム録音位置や伝搬を測定していない。
- 路面：滑らか `0`／標準 `0.35`（初期状態）／粗い `1`。粗さは主としてタイヤ音を増加させ、風音や車両物理を直接変更しない。

AudioWorklet新パラメーター：`listenerMode`（0/1、離散値を音響側で約120msクロスフェード）と`roadRoughness`（0..1）。`EngineAudio`が既存の`AudioTelemetry.listenerMode`を用い、現在の路面選択と併せて渡す。サンプル生成では配列/オブジェクトを割り当てず、音の出力は既存のDCブロッカー・soft limiter・Web Audioコンプレッサーを経由。

P5-Bの車種別「燃焼ソースの音色EQ」は保持し、今回の処理は別段の「車室内音響と暗騒音」の混合。フィルターは切替中も常時演算して履歴を保持し、急な設定変更を避ける。

## 合格条件・残る制約

- `tests/p5d-cabin-soundstage.test.mjs`：停車時に路面/風音ゼロ、車速依存、粗い路面の音量差、CABIN/ENGINE_BAYの違い、各バス独立、車種別音響設定、切替時のクリック・非有限値・ピーク、8/44.1/48/96kHzの安全性。
- `tests/worklet-bridge.test.mjs`：実際のWorkletブリッジへ各制御が伝達されること。
- `tests/pwa-build.verify.mjs`：新DSPモジュールが公開PWAキャッシュに存在し、画面のコントロールが本番HTMLに含まれること。
- 既存のP5-A/B/Cテスト、型チェック、ビルド、統合後のGitHub Pages配信も維持。

**未検証：** 実車録音の周波数スペクトル、プリウスMXWH60とオーラFE13の正確な遮音係数、車室内位置による空間定位、路面粗さと物理的NVHレベルの数値関係、実機での聴感や長時間性能。メーカー固有の車速制御閾値・車室EQ測定値を推定で断定しない。
