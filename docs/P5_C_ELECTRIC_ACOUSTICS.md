# P5-C 音響設計：MG1・MG2／EM47・発電機の別音源化

**状態:** 第3段階のプロシージャル音響改善。音は100%リアルタイム合成で、録音素材は使わない。

## 一次資料の根拠と適用範囲

- トヨタ「PRIUS Hybrid Synergy Drive」救援・技術資料：MG1は発電とエンジン始動、MG2は車輪駆動と回生を担う。https://techinfo.toyota.com/t3Portal/document/dm/T-DM-030-D/pdf/T-DM-030-D.pdf
- 日産「第2世代e-POWER」：エンジンは発電専用、車輪を駆動するのはモーターのみ。https://www2.nissan-global.com/JP/INNOVATION/TECHNOLOGY/ARCHIVE/E_POWER_GEN2/
- 日産「e-POWER control technology」：発電機用エンジンの作動は速度・アクセル要求・SOCなどに基づく。https://www.nissan-global.com/EN/INNOVATION/TECHNOLOGY/ARCHIVE/E_POWER_CONTROL/

これらは**動力・発電の役割の根拠**であり、モーター極数・キャリア周波数・歯数・音圧の実測根拠ではない。後者は開発用の推定/仮値。

## 実装した独立音源

| 音声レイヤー | 実装上の励振 | モード |
| --- | --- | --- |
| 駆動モーターの電磁次数＋高調波 | MG2/EM47回転数、トルク符号・負荷 | 駆動/回生 |
| 減速ギアの噛み合い相当音 | 駆動モーター軸回転数と推定次数 | 駆動/回生 |
| インバーター相当の高周波音 | 推定キャリア帯域、駆動負荷 | 駆動/回生 |
| 回生時に強調される独立次数 | 負のモータートルクと回生電力 | 回生 |
| 発電機の電磁次数 | MG1/オーラ発電機の軸回転数と発電量 | 発電 |
| 発電機の始動/モータリング音 | MG1/発電機回転数と始動/非燃焼回転指令 | 始動/非燃焼回転 |

**駆動モーターは発電用エンジンと直接同期しない**。プリウスではMG1の推定軸回転数を遊星歯車モデルから得る。オーラでは発電機の軸回転数をエンジン側から得る。どちらも自動車の機械機構を完全再現したものではない。

### P5-A テレメトリーとの結線

`AudioTelemetry`に `motorTorqueNormalized` と `generatorMotoringAmplitude`を追加。音声Workletの `motorTorque` / `generatorMotoring` にそれぞれ平滑化して渡す。既存の `motor` / `motorRpm` / `regen` / `generator` / `generatorRpm` / `electricProfile`は維持し、汎用モデルの後方互換性を保つ。

P5-Aの `RUNNING_FUELLED`では発電音、`STARTING`と`SPINNING_UNFUELLED`ではスタータ・モータリング音、`STOPPED`では回転機械の音声をゼロに向けて減衰。発電状態がゼロの時に発電機の発電音を誤って鳴らさない。

### 高周波・音量安全性

磁気次数のピッチは回転数に依存する。高回転数で上位倍音がナイキスト周波数へ近づいたら**倍音成分を徐々に減衰**させ、単純な周波数クリップによる擬似的な固定音・エイリアスを抑制する。48kHzだけでなく44.1/96/8kHzのDSP検証も追加。最大音量と急激なサンプル飛びをチェックし、既存のソフトリミッター・コンプレッサーを維持する。

## 完了していないこと

- 聴感上のプリウス・オーラらしさを実車音と比較・校正すること（実測FFT、録音位置の違い、スマホ機種別聴取）。
- 車室内マスキング（ロード・風・遮音）を物理的に再現するP5-D。
- メーカー固有モーター極数、PWMスイッチング周波数、ギア歯数・共鳴の実証。
- 車外の車両接近通報音の忠実な実装。今回の電磁音とは別レイヤーとして後期検討する。
