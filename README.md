# EngineSoundLab

スマートフォン向けの**加速音・パワートレーン・メーターシミュレーター**。Android Chrome / iPhone Safari を主な対象とする、開発初期のオープンソースプロジェクトです。

> **状態：公開プロトタイプ P3（合成音・近似ハイブリッド・車種別メーター）。実車の音響や制御を正確に再現する完成品ではありません。**

## 目指す体験

アクセル・ブレーキをスマートフォンで操作すると、車速・エンジン回転数・モーター駆動・発電制御が変化し、音と車種別メーターが連動する。

- **音声は合成方式が主役。** 録音に依存せず、燃焼・吸排気・モーター・走行音をリアルタイム生成する。**ハイブリッド（録音＋合成）は後から追加する任意機能**であり、合成音を完成させる妨げにしない。
- **走行モード優先**。停車中の空ぶかし機能は将来フェーズ。
- **メーター**: プリウス・オーラ等の車種別 *inspired* テーマ + SPORT / ENGINEERING 表示。メーカー公式UIの完全複製ではない。
- **対応**: モバイルファースト PWA。縦・横画面、タッチ操作、音源なしでも使えるオフライン基本機能。

## 初期車種

| 車種 | シミュレーション | エンジン・車輪の関係 |
| --- | --- | --- |
| トヨタ プリウス 60系 2.0L HEV (2WD) | 動力分割型ハイブリッド (THS) | エンジンとモーターを動力分割機構で協調 |
| 日産 オーラ FE13 (2WD) | 第2世代 e-POWER | エンジンは発電用、車輪はモーター駆動 |

プリウス60系THSとオーラFE13 e-POWERは**推定パラメーターによる試作モデル**として動作します。スカイライン V37、GR Supra、IS300h、Civic e:HEV、プリウス PHEVなどは将来候補。

## 現在試せる機能

- [Web版を開く](https://yrika819.github.io/EngineSoundLab/)（GitHub Pages）
- スマホでアクセル・ブレーキを操作、汎用AT、プリウスTHS近似、オーラe-POWER近似のRPM・車速を表示
- **3・4・6気筒の点火間隔・排気共鳴・吸気・走行音を合成**。気筒数は再生中も切替可能（走行物理は共通）。音源サンプル不要、録音音源なし
- **P3：プリウス風CHARGE/ECO/POWER、オーラ風クラシック/エンハンス、SPORT、ENGINEERINGのメーターを選択可能。**
- [Node上のDSPテスト](tests/synth-core.test.mjs)と[Worklet連携テスト](tests/worklet-bridge.test.mjs)をCIで実行

## P2の車両制御（試作）

車両選択で「汎用ガソリン車」「プリウス60系HEV（近似）」「オーラFE13 e-POWER（近似）」を切替できます。THSにはエンジン機械駆動とモーターの分担、e-POWERには発電専用エンジンと駆動モーターを別々に実装しました。バッテリーSOC、発電量、モーター出力、エンジン状態が確認でき、エンジン停止中は燃焼音が鳴らず、モーター音は残ります。

**注意：メーカー未公開の各制御閾値・バッテリー使用可能容量・ギア比などは推定/仮値です。メーカーの実車の正確な制御再現ではありません。**

## P3+ 電動駆動音の高度化（実験的）

ハイブリッドで聞こえる音は燃焼音とは独立して合成します。駆動モーター、減速ギア、インバーターに由来する成分、回生ブレーキ、発電用モーター/発電機を別々の音声レイヤーとして実装しています。プリウスとオーラで合成プロファイルを切り替えます。

**重要:** この音響モデルは推定・創作の周波数/音量設定による試作であり、実車の電動系の音を正確に録音・再現したものではありません。すべてオリジナルのリアルタイム合成音です。

## P5-B.1 車室音色・燃料カットの精度改善

先行して統合されたP5-Bの専用直4/直3エンジン音響合成を維持し、**プリウスの中域を抑えた車室音の方向性**を反映するピーキングEQを追加しました。プリウスは365Hz付近約-4.8dB、オーラは約-1.5dBの暫定設定です。アクセル操作に伴う吸気の過渡応答も約85msに延ばしました。燃料停止時は新しい点火イベントを即停止させ、残響のみ自然に減衰させます。

**これらの周波数・EQ・過渡応答値は合成用の推定値であり、実車メーカーの校正データではありません。** 車室内の実測音響比較・実機聴感評価は引き続き未完了です。

## P4 モバイルPWA・オフライン

- Android ChromeとiPhone Safariのホーム画面追加に対応するマニフェストとPNGアイコンを実装。
- 初回オンライン訪問後に、JS・CSS・合成音をオフラインで読み込むService Workerを導入。
- タブを隠したとき・画面回転・bfcache復帰時にペダルを解除し、音声を一時停止。再開にはタップが必要。
- 実機のオフライン・10分連続試験と電池消費測定は未完了。
- 詳細: [PWAと実機QA](docs/PWA.md)

## P5-B 車種別エンジン音色（試作）

- プリウス60系2.0 HEV（M20A-FXS）の直4らしい低域主体の排気・吸気・機械音を独立した合成プロファイルで実装。
- オーラFE13（HR12DE）の直3の燃焼周期を保ちながら、バランサーによる振動抑制を考慮した控えめな機械音と、発電用エンジンらしい音色を作成。
- **燃焼していないエンジン回転**（始動・停止・発電機を介した回転）には、排気燃焼音と区別した小さな機械音を合成。
- 車両切替時の音響プロファイルは滑らかに変更。エンジン合成は録音素材不要のまま。
- **注意：音色係数は実車録音やメーカーの測定値で校正されておらず、忠実度の聴感確認は未完了**。今後P5-C/D/Eでさらに調整する。

詳細：[車種別エンジン合成仕様](docs/AUDIO.md)

## データと権利

メーカー公表値、実測値、推定値、仮値は区別する。車名は説明用に言及し、メーターデザインは独自に描画する。録音音源・画像・第三者コードの無断転載はしない。開発中の仕様や実装はメーカー非公認で、実車の制御/安全操作を代替しない。

## P5-C: 独立した電動モーター・発電機・回生音（試作）

- **プリウス：** MG2駆動・回生、MG1発電・エンジン始動を別々の合成音源で表現。
- **オーラ：** EM47駆動と独立した発電機の音、非燃焼での回転音を表現。エンジンから車輪への機械駆動経路は追加しません。
- トルクの正負で音色を変え、減速ギアとインバーター相当の高周波成分を分離。高回転の高次成分はサンプリング周波数に応じて減衰し、折り返し雑音を抑えます。
- **注意：** モーターの極数・PWM周波数・減速機の歯数や実車の音圧は未測定です。設定は合成用の推定値で、実車音との聴感比較はP5-Eで行います。録音音源は一切使用しません。

[詳しい音響設計・検証内容](docs/P5_C_ELECTRIC_ACOUSTICS.md)

## P5-D：車室内サウンドステージ

- 車内と比較用エンジンルーム視点を切替可能。燃焼・非燃焼機械音・駆動モーター・発電機を独立して遮音・ミキシング。
- タイヤのロードノイズと風切り音を車速に連動して合成。路面の粗さ（滑らか／標準／粗い）を切替可能。
- PWAのオフライン音響、プリウス・オーラの動力制御、メーター、ペダルはそのまま維持。
- **注意：** 音量・周波数・遮音率は研究に基づいた初期推定値で、実車収録で校正されたものではありません。音源はすべてオリジナル合成です。

[技術設計と検証基準](docs/P5_D_CABIN_SOUNDSTAGE.md)

### P5-D.1：電動系の音が埋もれる問題の改善

プリウス・オーラの燃焼音が強すぎてMG2/駆動モーター・発電機の音が聞こえにくい問題を補正しました。車室内の推定ゲインを再調整し、`HYBRID SOUND BALANCE`から「標準」「電動音を強調」「エンジン音を強調」を聴き比べられます。標準モードも改善済みです。これは音響ミックスの選択のみで車両物理を変更せず、**実車の音響レベルに校正されたものではありません**。

[音源別の補正測定と技術資料](docs/P5_D_1_HYBRID_SOUND_BALANCE.md)

## P6: 高精細な車種別デジタルメーター

プリウス60系は中央速度表示＋CHG/ECO/PWRの弧状HVインジケーター、オーラFE13は左右対称の目盛り付きPOWER/スピードダイヤルと中央の電動フロー表示へ刷新。**オーラはスマホ幅でも左右2メーターを横並び維持**し、Classic/Enhancedを切替できます。SVG・CSSによる独自の表示デザインで、公式車両資料は画面構造の研究に限って参照しています。メーターの表示値は推定シミュレーション由来で実車ECUの校正値ではありません。

[公式資料とP6設計・検証方針](docs/GAUGES.md)
